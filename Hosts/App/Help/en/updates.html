Update Mosaic

Mosaic Companion checks for a new version of Mosaic once a day, prepares it, and installs it when you say so.

When a new version is ready

Mosaic Companion downloads it in the background and asks you in its window, with what’s new. If the window isn’t open, which is usual while Mosaic Companion opens at login, a notification tells you; click it to see the update.

  • Install and Relaunch replaces Mosaic Companion in Applications and opens the new version, which updates the screen saver too. If your account can’t change Applications, macOS asks for an administrator’s name and password.
  • Not Now asks again the next time Mosaic Companion opens. Until then, the window shows the new version with an Install… button.
  • Skip This Version stops Mosaic Companion offering that version. A later one is offered as usual.

Check now

Choose Mosaic Companion › Check for Updates…. This also offers a version you skipped.

Notifications

Mosaic Companion asks to send notifications only when you click Allow Notifications…, on the Updates page of the setup or in Settings, under Updates, and uses them only to say that a new version is ready. To change your answer, click Open Notification Settings… there, or open System Settings › Notifications › Mosaic.

Mosaic Companion installs only a new version signed as the one you have: a download signed by anyone else is refused.
