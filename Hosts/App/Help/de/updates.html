Mosaic aktualisieren

Mosaic Companion sucht einmal am Tag nach einer neuen Version von Mosaic, bereitet sie vor und installiert sie, wenn du es sagst.

Wenn eine neue Version bereitsteht

Mosaic Companion lädt sie im Hintergrund und fragt dich in seinem Fenster, mit den Neuerungen. Wenn das Fenster nicht geöffnet ist, was üblich ist, wenn sich Mosaic Companion bei der Anmeldung öffnet, informiert dich eine Mitteilung; klicke darauf, um das Update zu sehen.

  • Installieren und neu starten ersetzt Mosaic Companion im Ordner „Programme“ und öffnet die neue Version, die auch den Bildschirmschoner aktualisiert. Wenn dein Benutzeraccount den Ordner „Programme“ nicht ändern darf, fragt macOS nach Name und Passwort eines Administrators.
  • Später fragt beim nächsten Öffnen von Mosaic Companion erneut. Bis dahin zeigt das Fenster die neue Version mit einer Taste Installieren ….
  • Diese Version überspringen sorgt dafür, dass Mosaic Companion diese Version nicht mehr anbietet. Eine spätere wird wie gewohnt angeboten.

Jetzt suchen

Wähle Mosaic Companion › Nach Updates suchen …. So wird auch eine übersprungene Version angeboten.

Mitteilungen

Mosaic Companion fragt nur dann, ob es Mitteilungen senden darf, wenn du auf Mitteilungen erlauben … klickst, auf der Seite „Updates“ der Einrichtung oder in den Einstellungen unter „Updates“, und verwendet sie nur, um zu sagen, dass eine neue Version bereitsteht. Um deine Antwort zu ändern, klicke dort auf Mitteilungen öffnen … oder öffne Systemeinstellungen › Mitteilungen › Mosaic.

Mosaic Companion installiert nur eine neue Version, die so signiert ist wie die, die du hast: Ein Download mit einer anderen Signatur wird abgelehnt.
