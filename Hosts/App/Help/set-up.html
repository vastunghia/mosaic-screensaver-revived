Set up Mosaic

The first time you open Mosaic, a few pages set up the screen saver. Click Get Started, then Continue, to go on and Back to return; a page you leave unanswered stays in the Mosaic window, with what to do about it. To go through them again, choose Mosaic › Set Up Mosaic…. After an update that changes them, Mosaic shows them again by itself.

Applications

This page appears only if Mosaic is running from where it was downloaded. Click Move to Applications: Mosaic opens again from there. The screen saver and opening at login need the app to stay in one place.

On an account that is not an administrator, macOS asks for an administrator’s name and password first, as the Finder would. Each update moved there later asks again.

Photographs

Choose where the photographs come from: Photos library or A folder.

  • For the Photos library, click Allow Access… and allow Mosaic to access your photos.
  • For a folder, click Choose… and pick it. Mosaic includes the folders inside it too.

You need at least 100 photographs; a couple of thousand look best. Mosaic starts preparing them right away, in the background: it makes a small copy of each to build the mosaics from, and it can take a while. The Mosaic window shows how far it has got.

Screen Saver

Click Install…. Mosaic installs its screen saver; on the last page you choose it in System Settings.

In the Background

Turn on Open at login so that the screen saver keeps up with your library: at login Mosaic opens without a window and stays in the background. See Keep the photographs up to date.

Photos in iCloud

This page appears for the Photos library. It matters only if your library keeps its originals in iCloud: then Mosaic can download a sharp copy of the photographs it shows full screen. Choose Sharp close-ups only, or leave Nothing: if some close-ups turn out blurry, the Mosaic window says so later, with a button to change it. See Download from iCloud.

Updates

Mosaic checks for a new version once a day. Click Allow Notifications… and allow them, so that Mosaic can tell you when one is ready even if you never open its window. Mosaic uses notifications for nothing else. If you don’t allow them, new versions show only in the Mosaic window. See Update Mosaic.

Mosaic Is Set Up

The last page lists what is done; it says Almost Done while something is left. Click Open Screen Saver Settings… and choose Mosaic, under Other. On macOS 26 it opens Wallpaper instead, where the Screen Saver button leads to them. Then click Done: the Mosaic window opens.

The Mosaic window

Under the mosaic, the window says what the screen saver has: how many photographs are ready, whether the screen saver is installed and up to date, and a new version of Mosaic when there is one. Where something is missing, the row has a button that fixes it. When everything is in place, it says Ready. Below, In the Background turns opening at login on and off.
